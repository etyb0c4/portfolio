# RS—01

The portfolio of Rayan Sama (etyb0c4 / saiyanj1n): a sealed black box you take apart by scrolling.
Three.js + GSAP, no framework. Everything the site says lives in `src/data.js`.

```sh
npm ci
npm run dev        # http://localhost:5199
npm run build      # dist/
node tools/shoot.mjs .shots   # walk the page and screenshot every beat
```
